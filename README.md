# Expense Tracker

A simple JavaScript-based app to track income and expenses with a live balance update.

## 🔧 Technologies Used
- HTML
- CSS
- JavaScript

## 💡 Features
- Add income and expenses
- Auto-calculate total balance
- Visual transaction list with color-coded styling
